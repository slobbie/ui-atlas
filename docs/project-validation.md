# 프로젝트 점검 기록

이 양식은 사용자가 실제 프로젝트에서 점검 결과를 기록할 때 사용합니다. 빈 양식이며 검증 완료 기록이 아닙니다.

- 프로젝트:
- 화면 또는 컴포넌트:
- 대조한 사례 ID:
- UI Atlas 버전과 `data/manifest.json`의 `sourceSha256`:
- 점검 목적:
- 발견한 차이와 판단 근거:

| 확인할 내용 | 실제 결과 | 확인 방법 또는 남은 문제 |
| --- | --- | --- |
| 문구와 배치, 좁은 화면의 정렬 | 미확인 | |
| 주요 행동과 상태 변화 | 미확인 | |
| 진입과 퇴장, 크기 변화 등 해당 사례의 모션 | 미확인 | |
| 반복 입력과 중간 취소 | 미확인 | |
| 키보드와 포커스 이동 | 미확인 | |
| 움직임 줄이기 설정 | 미확인 | |
| 프로젝트 데이터 및 오류 처리 | 미확인 | |

해당하지 않는 항목은 그 이유를 남깁니다. 문제가 있으면 사례 ID와 재현 순서, 기대 동작, 실제 동작을 함께 기록합니다.
