# 출처 안내

이 패키지의 278개 사례는 기존 HTML 카탈로그의 UI와 모션, 구현 지시, 피할 구성, 출처 링크를 보존한 것입니다. 각 사례의 명세와 `data/cases.json`에 원본 출처가 있습니다.

출처에서 설명한 원칙과 UI Atlas의 미리보기는 구분합니다. 미리보기는 원본 서비스 화면의 정확한 복제나 공식 컴포넌트 배포본을 의미하지 않습니다. 조사 기록과 제안된 시각값도 개별 명세에 구분해 두었습니다.

`src/support`와 `site`에는 기존 미리보기에서 연결한 HTML 자료와 이미지가 포함돼 있습니다. 루트 LICENSE는 저장소의 MIT 라이선스입니다. 외부 출처의 자료와 이미지에 대한 권리까지 대신하지 않으며 해당 자료의 이용 조건은 각 출처를 따릅니다.

원문을 재확인하거나 프로젝트에 적용하면서 달라진 내용은 해당 사례 ID에 연결해 기록합니다. 이번 패키지 생성만으로 기존 모든 조사 기록을 새로 검증했다고 간주하지 않습니다.
