아래 시각 예시는 원본 화면의 재현이 아닌 직접 제작한 개념 시안입니다. 사례별 시안이 연결된 항목은 해당 시안을, 연결되지 않은 항목은 같은 UI 유형의 공통 개념도를 표시합니다. ‘공통 원칙·접근성’은 특정 UI 하나가 아니라 여러 화면에 적용하는 기준입니다. 안티 항목은 실제 발견된 문제와 적용 시 주의를 원래 조사 기록 그대로 구분합니다. 프롬프트 복사에는 연결된 UI·모션 시안의 구성과 피할 점도 포함됩니다.
